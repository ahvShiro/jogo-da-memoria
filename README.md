# Jogo da Memória

Jogo da memória desenvolvido com HTML, CSS e JavaScript básico, com tema inspirado em Super Mario World. As cartas exibem palavras de desenvolvimento web, carregadas de uma API externa com fallback local.

## Disponível para teste em

[jogomemoria.shiroshima.com.br](https://jogomemoria.shiroshima.com.br/)

## Funcionalidades

- Tabuleiro com **12** cartas (6 pares)
- Embaralhamento aleatório das cartas a cada partida
- Contador de tentativas
- Cronômetro da partida (tempo total até vencer)
- Registro de resultado em um servidor remoto ao finalizar
- Troca de tema claro/escuro com persistência no navegador
- Botão para reiniciar a partida
- Responsividade para dispositivos mobile

## Tecnologias usadas

HTML5, CSS3, JavaScript (ES Modules), Fetch API e LocalStorage
